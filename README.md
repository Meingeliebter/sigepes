# SIGEPES Frontend

Sistema de Informacion y Gestion Pesquera - Frontend (MVP).

## Stack
React 19, TypeScript, Vite, Material UI, React Router, React Query, Zustand, React Hook Form, Zod, MSW.

## Requisitos
- Node.js 22 LTS
- npm 10+

## Instalacion
npm install
npx msw init public --save
npm run dev
